# Simple Pacman task

Simple Pacman, a p5.js human behavioral task built on [mobeets/websockets_task](https://github.com/mobeets/websockets_task).

## Run

Install [uv](https://docs.astral.sh/uv/), then from this directory:

```sh
uv run python server.py
```

Open http://localhost:8000/?subject_id=TEST. Click **Play**, or press Enter/Space or gamepad South/Start. During a game, **Space**, **P**, or gamepad **Start** To move use arrow keys/WASD, gamepad D-pad, or left stick.
